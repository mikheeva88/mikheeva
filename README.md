# Эмулятор командной строки

Практическая работа №1 по дисциплине «Конфигурационное управление»,
вариант 18: эмулятор языка оболочки UNIX-подобной ОС.

Реализовано:

- Этап 1: REPL (графический интерфейс, парсер, команды ls, cd, exit);
- Этап 2: конфигурация (параметры командной строки, стартовый скрипт,
  отладочный вывод параметров).

## Общее описание

Эмулятор с графическим интерфейсом (tkinter). Пользователь вводит
команды в строку внизу окна, результат выводится в область над ней,
как в обычном терминале (REPL: прочитать команду, выполнить, вывести
результат, повторить).

Заголовок окна формируется из реальных данных ОС:
`Эмулятор - [username@hostname]`.

Команды `ls` и `cd` пока являются заглушками: они выводят своё имя и
аргументы. Виртуальная файловая система (VFS) будет подключена на
Этапе 3, сейчас её путь только запоминается и выводится в отладке.

## Структура проекта

```
src/emulator/shell_parser.py  разбор строки на команду и аргументы
src/emulator/commands.py      команды ls, cd, exit и их выполнение
src/emulator/system_info.py   имя пользователя и хоста, заголовок окна
src/emulator/config.py        параметры командной строки, отладочный вывод
src/emulator/script.py        чтение и выполнение стартового скрипта
src/emulator/gui.py           графический интерфейс (окно, ввод, вывод)
src/emulator/main.py          точка входа
tests/                        модульные тесты (unittest)
examples/                     примеры стартовых скриптов эмулятора
scripts/                      скрипты ОС для проверки параметров запуска
run.sh, run.bat, Makefile     запуск приложения и тестов
```

## Описание функций и настроек

### Параметры командной строки (`config.py`)

| Параметр | Описание |
|---|---|
| `--vfs PATH` | путь к физическому расположению VFS |
| `--script PATH` | путь к стартовому скрипту |
| `-h`, `--help` | справка по параметрам |

Оба параметра необязательны, порядок любой, допустима запись
`--vfs=PATH`. Сокращённые имена (`--vf`) не поддерживаются. При
неизвестном параметре или параметре без значения программа выводит
сообщение об ошибке в консоль и завершается, окно не открывается.

Функции модуля:

- `parse_args(argv)` разбирает параметры и возвращает `Config`.
- `format_debug(config)` формирует отладочный вывод всех параметров.

**Отладочный вывод.** При запуске в окне показываются значения всех
параметров (не заданные помечаются `(не задан)`):

```
[debug] Параметры запуска:
[debug]   --vfs    = vfs_data
[debug]   --script = examples/basic.txt
```

### Стартовый скрипт (`script.py`)

Стартовый скрипт это текстовый файл (UTF-8), по одной команде эмулятора
в строке. После запуска окна команды выполняются последовательно, на
экране видно и введённую строку, и результат, как в диалоге с
пользователем (между строками небольшая пауза).

Правила выполнения:

- пустые строки и строки-комментарии (начинаются с `#`) пропускаются;
- строка с ошибкой (неизвестная команда, неверные аргументы) не
  прерывает скрипт: сообщение об ошибке выводится красным цветом, затем
  выполняется следующая строка;
- команда `exit` завершает скрипт и закрывает эмулятор;
- если файл скрипта не найден или не читается, выводится сообщение
  об ошибке, и эмулятор продолжает работу в интерактивном режиме;
- после выполнения последней строки эмулятор остаётся открытым.

Функции модуля: `load_script(path)` читает файл, `is_skipped(line)`
определяет пропускаемые строки, `run_script(lines)` выполняет строки.

### Команды (`commands.py`)

- `ls [args...]` заглушка: выводит имя команды и аргументы.
- `cd [args...]` заглушка: выводит имя команды и аргументы.
- `exit` завершает работу эмулятора. Если переданы аргументы, выводит
  ошибку «слишком много аргументов» и не завершается.
- Неизвестная команда: сообщение `<имя>: команда не найдена`.
- Пустая строка: ничего не происходит.
- `execute(line)` разбирает строку и выполняет команду, возвращает
  `CommandResult` (`output`, `is_error`, `should_exit`).

### Парсер (`shell_parser.py`)

- `parse_line(line)` делит строку по пробельным символам: первое слово
  команда, остальные аргументы. Несколько пробелов подряд считаются
  одним разделителем. Для пустой строки возвращает `None`. Кавычки не
  поддерживаются.

### Данные ОС (`system_info.py`)

- `get_username()` и `get_hostname()` берут имя пользователя и имя
  компьютера у ОС (если ОС не вернула, подставляется `unknown`).
- `format_title(user, host)` формирует заголовок окна.
- `format_prompt(user, host)` формирует приглашение `user@host:~$`.

## Требования

- Python 3.8 или новее.
- Модуль tkinter. В Windows и macOS он входит в стандартную установку
  Python. В Debian/Ubuntu: `sudo apt install python3-tk`.
- Сторонние библиотеки не нужны.

## Сборка и запуск

Сборка не требуется. Запуск эмулятора:

```
run.bat [параметры]          # Windows
./run.sh [параметры]         # Linux / macOS
make run ARGS="параметры"    # через Makefile
```

Без скриптов (из корня репозитория):

```
PYTHONPATH=src python3 -m emulator [параметры]          # Linux / macOS
set PYTHONPATH=src && python -m emulator [параметры]    # Windows (cmd)
```

## Запуск тестов

```
make test
```

или

```
PYTHONPATH=src python3 -m unittest discover -s tests -v    # Linux / macOS
set PYTHONPATH=src && python -m unittest discover -s tests -v    # Windows
```

### Скрипты ОС для проверки параметров запуска

В папке `scripts/` лежат скрипты, которые запускают эмулятор с разными
параметрами. Эмулятор открывается окном, после его закрытия запускается
следующий вызов. Для каждой ОС есть пары `.bat` (Windows) и `.sh`
(Linux/macOS, запуск командой `sh scripts/имя.sh`):

| Скрипт | Что проверяет |
|---|---|
| `test_basic` | запуск без параметров, только `--vfs`, только `--script`, оба |
| `test_errors` | скрипт с ошибочными строками, несуществующий файл скрипта, `exit` в скрипте, неизвестный параметр |
| `test_syntax` | запись `--параметр=значение`, другой порядок, параметр без значения, `--help` |

Примеры стартовых скриптов эмулятора лежат в `examples/`:
`basic.txt` (без ошибок), `with_errors.txt` (ошибочные строки),
`with_exit.txt` (команда `exit` посередине).

## Примеры использования

Запуск со стартовым скриптом и путём к VFS:

```
run.bat --vfs vfs_data --script examples\with_errors.txt
```

Окно покажет:

```
Эмулятор командной строки. Доступные команды: ls, cd, exit.
[debug] Параметры запуска:
[debug]   --vfs    = vfs_data
[debug]   --script = examples\with_errors.txt
Выполнение стартового скрипта: examples\with_errors.txt
user@host:~$ ls first
Команда: ls
Аргументы (1): first
user@host:~$ foo bar
foo: команда не найдена
user@host:~$ exit now
exit: слишком много аргументов
user@host:~$ cd third
Команда: cd
Аргументы (1): third
Стартовый скрипт выполнен.
```

Интерактивный режим (без параметров):

```
user@host:~$ ls -l /home
Команда: ls
Аргументы (2): -l /home

user@host:~$ foo
foo: команда не найдена

user@host:~$ exit
```

Последняя команда закрывает окно эмулятора.
