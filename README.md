# Эмулятор командной строки (Этап 1: REPL)

Практическая работа №1 по дисциплине «Конфигурационное управление»,
вариант 18: эмулятор языка оболочки UNIX-подобной ОС.

## Общее описание

Минимальный прототип эмулятора с графическим интерфейсом (tkinter).
Пользователь вводит команды в строку внизу окна, результат выводится
в область над ней, как в обычном терминале (REPL: прочитать команду,
выполнить, вывести результат, повторить).

Заголовок окна формируется из реальных данных ОС:
`Эмулятор - [username@hostname]`.

На этом этапе команды `ls` и `cd` являются заглушками: они выводят своё
имя и аргументы. Файловая система пока не подключена.

## Структура проекта

```
src/emulator/shell_parser.py  разбор строки на команду и аргументы
src/emulator/commands.py      команды ls, cd, exit и их выполнение
src/emulator/system_info.py   имя пользователя и хоста, заголовок окна
src/emulator/gui.py           графический интерфейс (окно, ввод, вывод)
src/emulator/main.py          точка входа
tests/                        модульные тесты (unittest)
run.sh, run.bat, Makefile     запуск приложения и тестов
```

## Описание функций и настроек

### Парсер (`shell_parser.py`)

- `parse_line(line)` делит строку по пробельным символам. Первое слово
  становится командой, остальные аргументами. Несколько пробелов подряд
  считаются одним разделителем. Для пустой строки возвращает `None`.
  Кавычки и экранирование не поддерживаются.

### Команды (`commands.py`)

- `execute(line)` разбирает строку и выполняет команду. Возвращает
  `CommandResult` с полями `output`, `is_error`, `should_exit`.
- `ls [args...]` заглушка: выводит имя команды и аргументы.
- `cd [args...]` заглушка: выводит имя команды и аргументы.
- `exit` завершает работу эмулятора (закрывает окно). Если переданы
  аргументы, выводит ошибку «слишком много аргументов» и не завершается.
- Неизвестная команда: сообщение `<имя>: команда не найдена`.
- Пустая строка: ничего не происходит.

### Данные ОС (`system_info.py`)

- `get_username()` имя пользователя (`getpass.getuser`).
- `get_hostname()` имя компьютера (`socket.gethostname`).
- `format_title(user, host)` заголовок окна `Эмулятор - [user@host]`.
- `format_prompt(user, host)` приглашение `user@host:~$`.

Если ОС не вернула имя, подставляется `unknown`.

### Настройки

Параметров командной строки и конфигурационных файлов на этом этапе нет
(они появятся на Этапе 2).

## Требования

- Python 3.8 или новее.
- Модуль tkinter. В Windows и macOS он входит в стандартную установку
  Python. В Debian/Ubuntu: `sudo apt install python3-tk`.
- Сторонние библиотеки не нужны.

## Сборка и запуск

Сборка не требуется. Запуск эмулятора:

```
./run.sh          # Linux / macOS
run.bat           # Windows
make run          # через Makefile
```

Без скриптов (из корня репозитория):

```
PYTHONPATH=src python3 -m emulator          # Linux / macOS
set PYTHONPATH=src && python -m emulator    # Windows (cmd)
```

## Запуск тестов

```
make test
```

или

```
PYTHONPATH=src python3 -m unittest discover -s tests -v    # Linux / macOS
set PYTHONPATH=src && python -m unittest discover -s tests -v    # Windows
```

## Примеры использования

```
user@host:~$ ls
Команда: ls
Аргументы (0): (нет)

user@host:~$ ls -l /home
Команда: ls
Аргументы (2): -l /home

user@host:~$ cd   docs   photos
Команда: cd
Аргументы (2): docs photos

user@host:~$ foo
foo: команда не найдена

user@host:~$ exit now
exit: слишком много аргументов

user@host:~$ exit
```

Последняя команда закрывает окно эмулятора.
